CAPA PUSKESMAS NGALUPOLO

Aplikasi dipublikasikan di subfolder /capa/ dalam repository RESEPOBAT agar aplikasi resep obat yang sudah ada tidak tertimpa.

Data tersimpan lokal pada browser/perangkat ini. Tidak ada login, database bersama, atau sinkronisasi. Ekspor JSON secara berkala. Jangan masukkan identitas pasien atau data sensitif.

Untuk instalasi: buka URL HTTPS pada Chrome Android, menu tiga titik, lalu pilih Tambahkan ke layar utama / Instal aplikasi jika tersedia.

Versi ini adalah prototipe awal. Penggunaan resmi lintas pengguna memerlukan autentikasi, kontrol akses, audit trail, penyimpanan server dan kebijakan privasi yang sesuai.
