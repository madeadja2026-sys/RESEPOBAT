# Manajemen Puskesmas Ngalupolo (PWA)

Aplikasi PWA manajemen terpadu, terpisah dari halaman utama dan modul Pantau Farmasi.

## Modul
Dashboard; Agenda Kepala Puskesmas; Rencana Kerja; Monitoring Klaster ILP; SDM dan Jadwal Petugas; Logistik Obat/BMHP; Anggaran dan Realisasi; Sarana/Prasarana/Aset; Mutu, Risiko, CAPA; Supervisi Pustu/Desa; Rapat dan Keputusan.

Fitur: tambah/edit/hapus/duplikasi catatan, pencarian, ekspor CSV, cetak/PDF, backup dan restore JSON, penyimpanan lokal, cache offline.

## Penyimpanan dan keamanan
Data disimpan di localStorage browser pada perangkat. Tidak ada sinkronisasi server. Data bisa hilang jika data situs/browser dihapus; ekspor JSON secara berkala. Gunakan data dummy saat uji coba. Jangan masukkan identitas pasien atau data kesehatan yang dapat mengidentifikasi pasien.

## Instalasi Android
Buka URL di Chrome setelah GitHub Pages selesai deploy; menu ⋮ → Instal aplikasi atau Tambahkan ke layar utama. Buka sekali saat online agar file dasar tersimpan, lalu uji mode pesawat.
